# Scenario atlas — sixteen patterns, eight of them animated

**What this is.** Sixteen patterns. S1 to S8 happen inside one run and each has its own
sixty-second animation plus a normal and an abnormal still. S9 to S16 only appear when a
year of experiments is opened together, and each has a normal and an abnormal figure. Every trace is generated
from the parameters in `scen.py`. Nothing here comes from an instrument, a laboratory
file or a laboratory procedure, and no identifier or measured value appears anywhere in
these images.

## The animations

`assets/scenarios/missy_scenario_S<n>_60s.gif` — one per scenario, S1 to S8. Each is
1920 x 1080, 600 frames at 100 ms, **60.0 s measured**, looping for ever: a fifteen-second
build from cycle 1 to cycle 45 in two large panels (normal left, abnormal right), played
four times. `documentation/scenario_atlas/missy_scenario_S<n>_60s.mp4` is the same
60 seconds as H.264 for slide software.

`assets/scenarios/missy_scenarios_60s_1920.gif` — the overview that shows all eight in one
minute, four cycles of fifteen seconds with two scenarios per cycle.

- 1920 x 1080, 600 frames, 100 ms per frame, **60.0 s exactly**, loops for ever.
- Four cycles of fifteen seconds. Each cycle builds one acquisition from cycle 1 to
  cycle 45 in four panels at once: two scenarios, normal on the left, abnormal on the right.
  - cycle 1 of 4 — S1 technical fault, S2 human mistake
  - cycle 2 of 4 — S3 wrong reference material, S4 wrong dilution
  - cycle 3 of 4 — S5 amplified controls, S6 probe unsuited to the channel read
  - cycle 4 of 4 — S7 deviation from the protocol, S8 inhibition and carry-over
- `missy_scenarios_60s_1920.mp4` is the same 60 seconds as H.264 for slide software that
  handles video better than an animated GIF.

Nothing is drawn into the frames except the axes, the scenario code, the words
`normal` / `abnormal`, the cycle counter, the note `synthetic data`, the legend and the
MISSY mark with `RUO` and `NOT VALIDATED`. **The explanations are not in the image**;
they are HTML text in the block below the figure.

## The still figures

`assets/scenarios/missy_scenario_S<n>_<normal|abnormal>.png` — 2400 x 1500, one image for
the normal state and one for the abnormal state of all sixteen patterns.

## The historical views, S9 to S16

These are what a year of runs shows and a single run cannot. Each uses a different kind of
chart, so between them they cover the graph types the page offers:

| Code | View | Chart |
|---|---|---|
| S9  | calibrator shift between lots | control chart with 2 SD and 3 SD limits |
| S10 | efficiency falling over the year | run scatter with a rolling mean and an acceptance band |
| S11 | contamination episode | monthly rate against a limit from the first six months |
| S12 | repeatability getting worse | within-run spread, run by run |
| S13 | one analyst apart from the others | box plots by the person who ran it |
| S14 | position effect on the plate | heat map of mean deviation by well position |
| S15 | calibration lines that no longer agree | every calibration line of the year overlaid |
| S16 | digits that were not measured | histogram of the last reported decimal |

They are generated by `hist.py`, which builds a calendar of 104 runs over twelve months.
The analysts are called A, B, C and D and the instruments are not named; nothing in them
refers to a real person, plate, run or laboratory.

## Putting it in the page

`missy_scenario_block.html` holds a `<style>` and a `<section class="missy-scn">`. Paste it
where the atlas should appear. It refers to the images by relative path, so the page stays
the size it is now; the `assets/scenarios/` folder ships beside the page. To make the page
self-contained instead, replace each `src="assets/..."` with a `data:` URI — that adds
about 2.4 MB of base64 for the animation alone, which is why it is not the default.

`preview.html` is a standalone page for checking the block on its own.

## Rebuilding

    python3 scen.py        # per-run parameters and captions
    python3 hist.py        # year-of-runs parameters and captions (S9-S16)
    python3 makeframes.py  # 600 frames for the overview animation
    python3 makeone.py     # 150 frames per scenario for the eight single-scenario loops
    bash    build_gifs.sh  # the eight 60 s GIFs and MP4s
    python3 mkhtml.py      # regenerates the HTML block from both caption sets
    ffmpeg -framerate 10 -i frames/f%04d.png -vf "palettegen=max_colors=200:stats_mode=diff" pal.png
    ffmpeg -framerate 10 -i frames/f%04d.png -i pal.png \
      -lavfi "paletteuse=dither=bayer:bayer_scale=3:diff_mode=rectangle" -loop 0 out.gif

Edit the captions in `scen.py` and re-run `mkhtml.py`; the text in the page and the text in
this folder stay in step because they come from the same place.
