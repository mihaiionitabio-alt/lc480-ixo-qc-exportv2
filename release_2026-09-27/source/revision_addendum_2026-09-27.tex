\sect{1. Scope of the update}
The 25 September 2026 PDF (1,117 pages) remains the document body. The pages below describe only code and measured
behaviour added after it.
\begin{itemize}
\item Public page identity: heading, document title and blue status bar.
\item Bottom page bar: language selector and one \emph{Download website} button.
\item Static hosting: inline empty favicon.
\item Command mode: option reference (\texttt{COMMAND\_MODE.md}), full-example lines in the script template and
      \texttt{target=all} meaning every target.
\item Default script: each control chart selected with its own chart type.
\item Console mode: labelled keys press their buttons.
\end{itemize}
\textbf{Document rule:} this file is the 25 September PDF followed by this addendum. The append-only method keeps all
existing page geometry and page text intact.

\sect{4. Command mode}
A complete option reference is delivered as \texttt{COMMAND\_MODE.md} (in this release folder). It lists the line
syntax, every command, name patterns, the accepted shape of every option value, which figures actually use
\texttt{target} and \texttt{control}, all 58 control charts with their own type and suitable \texttt{type} values, a
complete commented hand-over script and the error messages.

The Script-box template now carries a \texttt{\#~~~full example:} line under every \texttt{\#~\ldots~options:} line,
with every option filled in, and two header notes:
\begin{lstlisting}[numbers=none]
# target=all (or target= left empty) means every target; target=<name> must match a target name exactly.
# control=<number> is the position of the control in SOP section 3, counted from 0.
# img:curves options: target=<text>; signal=...; log=...
#   full example: select img:curves target=HPV16 signal=drn log=yes   (used by this figure: target, signal, log)
\end{lstlisting}

\textbf{Correction.} Before this revision \texttt{target=all} was compared as a target literally named ``all'', so the
shipped template drew empty curve, plate, standard-curve, end-point and control figures. \texttt{target=all} (any
case) now means every target, and \texttt{img:curves} with \texttt{target=all} draws every target instead of only
the first.
\begin{lstlisting}[firstnumber=11424]
  /* target=all (any case) is the documented way to ask for every target; it must not be read as a target called "all" */
  const allTargets=/^all$/i.test(o.target||"");
  return {g,ri,run:RUNS[ri],target:allTargets?"":o.target||(g.id==="curves"?((typeof gTargets==="function"&&RUNS[ri]?gTargets(RUNS[ri])[0]:"")||""):""),
\end{lstlisting}

\sect{6. Console mode keyboard keys}
The Console mode buttons showed keys (1--9, 0, $-$, +, arrows) but no key was handled outside the chart-type and
x-axis pick lists. A key listener now presses the button that currently shows the key: digits as labelled,
\texttt{-} or \texttt{$-$} (U+2212) zoom out, \texttt{+} or \texttt{=} zoom in, and the arrow keys pan.
\begin{itemize}
\item Active only while Console mode is open.
\item Never while a pick list is open; the list keeps its own 1--9 / 0 / Escape keys.
\item Never while typing in a text field, and never with Ctrl, Alt or Cmd, so browser zoom (Ctrl~+ / Ctrl~$-$) is
      unchanged.
\item The reset-view button (\raisebox{0pt}{$\circlearrowleft$}) has no key and stays click-only.
\end{itemize}
\begin{lstlisting}[firstnumber=8167]
  document.addEventListener("keydown",e=>{                 /* without a sheet, a key presses the button that shows it */
    if(!MG.open||MG.sheet||e.defaultPrevented||e.ctrlKey||e.metaKey||e.altKey)return;
    const tg=e.target,tag=tg&&tg.tagName;
    if(tag==="INPUT"||tag==="TEXTAREA"||tag==="SELECT"||(tg&&tg.isContentEditable))return;
    const key={"-":"(*$-$*)","=":"+",ArrowLeft:"(*$\leftarrow$*)",ArrowRight:"(*$\rightarrow$*)",ArrowUp:"(*$\uparrow$*)",ArrowDown:"(*$\downarrow$*)"}[e.key]||e.key;
    const b=[...document.querySelectorAll("#mg-actions .mg-act")].find(x=>{const k=x.querySelector(".k");return k&&k.textContent.trim().split(/\s/)[0]===key;});
    if(!b)return;
    e.preventDefault();b.click();
  });
\end{lstlisting}
