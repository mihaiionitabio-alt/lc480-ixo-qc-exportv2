\chapter{Complete production source}\label{app:source}

\readingnote{This appendix is the exact production HTML snapshot used for the release hash in Chapter~\ref{ch:rdml}.}

\begin{itemize}
\item File: \texttt{qpcr\_qc\_forensics.html}.
\item Length: 11,774 lines; 918,067 bytes.
\item Companion \texttt{index.html}: byte-identical.
\item The listing includes markup, styles, embedded data, JavaScript, exchange-file input, exports and event handlers.
\item Two kinds of line are too long for the width of the page. A long run of Latin characters is
broken by the listing engine, which is given break opportunities inside such a run; the breaks are
invisible and change nothing in the file. A long run of ideographs the engine cannot break at all:
189 such lines are wrapped here instead. A wrapped line carries its number once, on its first row,
so every line still shows its true number in the file. Nothing is lost and nothing overflows the box.
\end{itemize}
